# Aurelia Resort — React

React/Vite conversion of the supplied Aurelia Resort HTML/CSS design.

## Project structure

- `src/App.jsx` — main page composition
- `src/components/` — separate React components
- `src/style.css` — original resort styling
- `src/main.jsx` — React entry point

## Run

1. Install Node.js (LTS recommended).
2. Open this folder in VS Code.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local Vite URL shown in the terminal.

## Included React functionality

- Automatic 5-image hero slideshow every 5 seconds
- Hero slide indicators
- Responsive mobile navigation
- Gallery lightbox with Escape-to-close
- Booking form handled with React state
- Smooth navigation through the existing section IDs

The image URLs remain the Unsplash URLs from the supplied design, so no local image files are required.
